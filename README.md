# SPF25
## CPSA Model Usage
1. **Install the [Haskell Platform](https://www.haskell.org/downloads/)**
3. **Install CPSA**
    ```bash
    cabal update
    cabal install cpsa
    ```
4. **Compile the models**
    ```bash
    echo build | ghci Make4.hs
    ```
5. **The output will be in an .xhtml file such as sdls_replay.xhtml**
